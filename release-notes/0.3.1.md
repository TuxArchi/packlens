# PackLens v0.3.1

Actualización de precios de PackLens Pro.

## Cambiado

- **Pro mensual**: 4.99 USD/mes.
- **Pro anual**: 39 USD/año, con un ahorro de 20.88 USD frente al mensual.
- La pantalla **Ajustes → Licencia** muestra los precios en USD.
- Landing, banner, README y términos actualizados.

## Notas

- Sin cambios funcionales.
- Add-on ID: `packlens@packlens.app`.
- Requiere Firefox 142+.
- Checksums en `SHA256SUMS`, adjunto a la release.
