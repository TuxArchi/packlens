# PackLens v0.2.1

Primera release pública del núcleo gratuito.

## Lo que incluye

- **Packaging Score**: miniatura y título con desglose y recomendaciones.
- **SEO Score**: descripción, tags y colocación de la keyword.
- **Inspector de competencia** en `/watch`: tags reales, visitas/hora y datos del video.
- **Outliers de canal**: mediana y multiplicador de los últimos 30 videos.
- **Keyword research**: dificultad, interés, top 10, recomendaciones y tags sugeridos.
  - Modo API con tu clave gratuita de YouTube Data.
  - Modo sin clave experimental (visitas redondeadas, sin suscriptores).
- **Aplicar a Studio**: añade los tags que falten y aplica títulos recomendados con confirmación.
- **YouTube Studio**: miniatura de videos programados, tags detrás de «Mostrar más» y botón flotante.
- **Atajo `Alt+Shift+P`** para abrir el panel desde cualquier pestaña.

## Instalación

### Temporal

1. Descarga el ZIP de esta release.
2. `about:debugging#/runtime/this-firefox`
3. **Cargar complemento temporal…** → selecciona `manifest.json` dentro del ZIP descomprimido.

### Permanente

El ZIP no está firmado. Para una instalación permanente, súbelo a [addons.mozilla.org](https://addons.mozilla.org/developers/) como unlisted/autodistribución y abre el `.xpi` firmado.

## Atajo

`Alt+Shift+P` abre el panel. Se puede cambiar en `about:addons` → engranaje → **Administrar atajos de extensiones**.

## Notas

- Add-on ID público: `packlens@packlens.app`.
- Sin telemetría, sin servidor y sin código remoto.
- La API key de YouTube es gratuita; la cuota es 100 búsquedas/día + 10.000 unidades/día.
- Los tags sugeridos son frases de títulos del top 10, no los tags reales de los competidores.

## Limitaciones conocidas

- La UI de Studio cambia a menudo; los selectores pueden requerir ajustes.
- El modo sin clave puede fallar si YouTube pide consentimiento o limita las peticiones.
- La miniatura de un video programado usa una URL firmada; si caduca, recarga la página de Studio.
