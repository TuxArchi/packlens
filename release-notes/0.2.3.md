# PackLens v0.2.3

Una sola interfaz para el botón y el atajo.

## Corregido

- **`Alt+Shift+P` y el icono de la barra** ahora abren y cierran la **misma ventana** que el botón de Studio. Antes toggleaban el sidebar integrado y la ventana del botón se quedaba abierta.
- El comando reservado `_execute_sidebar_action` se sustituye por un comando custom `toggle-panel`.
- Al abrir la ventana se **cierra el sidebar integrado** si estaba abierto, para no tener dos interfaces.
- El ID de la ventana se guarda en `storage.local` y se valida antes de cerrarla, aunque el background se haya descargado.
- El sidebar integrado sigue disponible en **Ver → Barra lateral → PackLens**, pero ya no se abre al instalar.

## Instalación

### Temporal

1. Descarga el ZIP de esta release.
2. `about:debugging#/runtime/this-firefox`
3. **Cargar complemento temporal…** → `manifest.json` del ZIP descomprimido.

### Permanente

El ZIP no está firmado. Súbelo a [addons.mozilla.org](https://addons.mozilla.org/developers/) como unlisted/autodistribución y abre el `.xpi` firmado.

## Notas

- Add-on ID: `packlens@packlens.app`.
- Si tenías el sidebar integrado abierto, el primer `Alt+Shift+P` lo cerrará y abrirá la ventana.
- Checksums en `SHA256SUMS`, adjunto a la release.
