# PackLens v0.2.2

Corrección del botón de YouTube Studio y del panel desacoplado.

## Corregido

- El **botón flotante de Studio** ya abre PackLens de verdad: si Firefox no permite abrir el sidebar desde un content script (gesto de usuario), abre el panel en una **ventana propia**.
- La ventana se **enfoca** si ya está abierta, en lugar de duplicarse.
- La ventana queda vinculada a la pestaña de Studio con `?tabId=`, así que sigue el video aunque la ventana no sea la pestaña activa.
- El atajo `Alt+Shift+P` sigue abriendo el **sidebar** de Firefox.

## Instalación

### Temporal

1. Descarga el ZIP de esta release.
2. `about:debugging#/runtime/this-firefox`
3. **Cargar complemento temporal…** → `manifest.json` del ZIP descomprimido.

### Permanente

El ZIP no está firmado. Súbelo a [addons.mozilla.org](https://addons.mozilla.org/developers/) como unlisted/autodistribución y abre el `.xpi` firmado.

## Notas

- Add-on ID: `packlens@packlens.app`.
- Sin telemetría, sin servidor y sin código remoto.
- El botón abre una ventana; el atajo abre el sidebar. Son dos formas del mismo panel.
- Checksums en `SHA256SUMS`, adjunto a la release.
