# PackLens v0.3.0

Packaging, SEO y rendimiento para YouTube, ahora con un núcleo gratuito más
completo y un plan Pro opcional.

## Lo nuevo

### Free

- **Packaging Score** también en videos programados.
- **SEO de descripción** con keyword, tags, enlaces y capítulos.
- **Auditoría completa del canal**: hasta 500 videos, mediana, outliers y bajo rendimiento.
- **Resumen de 48 h**: vistas/día, engagement, cambios de metadatos y comparación con el canal.
- **Optimizador de descripción básico**: introducción SEO, tags al final, 3 hashtags, diff y aplicación en Studio.
- **Keywords** con API o modo sesión.
- Aplicar tags y título con confirmación.

### Pro

- **Generador avanzado de títulos**: 10 variantes puntuadas.
- **Descripción avanzada** con términos y hashtags de la competencia.
- **Analytics CSV**: CTR, impresiones, AVD y % medio visto.
- **Exportaciones** de auditoría, keywords, recomendaciones y rendimiento en CSV/JSON.
- **3 dispositivos**, **7 días de prueba** y **7 días de gracia offline**.

Precio de lanzamiento:

- **99 MXN/mes**
- **998 MXN/año**

La licencia se activa en **Ajustes → Licencia** con la key que envía Lemon
Squeezy.

## Corregido

- El panel mantiene los datos al cambiar entre Detalles, Analytics, Comentarios y
  otras secciones de Studio.
- Se recuperan tags y metadatos públicos de videos ya publicados.
- Se expanden automáticamente los tags ocultos en videos pendientes.
- `Alt+Shift+P` vuelve a abrir y cerrar el **sidebar integrado**.
- El botón de Studio y el icono de la barra abren la ventana desacoplada.

## Privacidad

- Sin servidor propio, sin telemetría y sin IA.
- La license key solo se envía a Lemon Squeezy.
- La API key de YouTube y las consultas van a Google.
- El CSV de Studio se procesa localmente.

## Instalación

### Temporal

1. Descarga el ZIP de esta release.
2. `about:debugging#/runtime/this-firefox`
3. **Cargar complemento temporal…** → `manifest.json` del ZIP descomprimido.

### Permanente

El ZIP no está firmado. Súbelo a [addons.mozilla.org](https://addons.mozilla.org/developers/)
como unlisted/autodistribución y abre el `.xpi` firmado.

## Notas

- Add-on ID: `packlens@packlens.app`.
- Requiere Firefox 142+.
- Checksums en `SHA256SUMS`, adjunto a la release.
- OAuth de YouTube Analytics queda para v0.4.0.
