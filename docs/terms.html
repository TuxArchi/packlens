Términos de uso

Vigente desde el 1 de noviembre de 2026 · PackLens 0.3.0

Al instalar o usar PackLens aceptas estos términos. Si no estás de acuerdo, no uses la extensión.

1. Licencia del código

El código de PackLens se publica bajo la licencia MPL-2.0. Puedes leerlo, modificarlo y redistribuirlo conforme a esa licencia. Las funciones Pro también son públicas; se activan con una license key.

2. PackLens Pro

  • Pro se vende como suscripción mensual o anual a través de Lemon Squeezy.
  • El precio de lanzamiento es 4.99 USD/mes o 39 USD/año, con impuestos aplicables calculados en el checkout.
  • La suscripción incluye una prueba de 7 días cuando está disponible en el checkout.
  • Una licencia permite hasta 3 dispositivos en el plan mensual o 5 en el plan anual.
  • La suscripción se renueva automáticamente hasta que la canceles.
  • Puedes desactivar un dispositivo desde Ajustes para liberar una activación.

3. License key

La license key es personal. No la publiques ni la compartas. PackLens valida la clave contra Lemon Squeezy y puede revocar el acceso local si la suscripción caduca, se desactiva o se supera el límite de dispositivos. El gate es una medida de comodidad, no un sistema DRM.

4. Uso aceptable

No uses PackLens para infringir derechos de autor, saltarte límites de terceros, automatizar spam o vulnerar los términos de YouTube, Google o Lemon Squeezy. Eres responsable de las credenciales y API keys que configures.

5. Disponibilidad y cambios

PackLens se ofrece “tal cual”. Podemos cambiar funciones, precios o límites en versiones futuras. Los precios de fundador se mantienen para quienes compren durante el lanzamiento, salvo cancelación o impago.

6. Garantías y responsabilidad

No garantizamos resultados de posicionamiento, visitas, ingresos ni cambios concretos en YouTube. En la medida permitida por la ley, PackLens no responde por daños indirectos, lucro cesante o pérdida de datos derivados del uso de la extensión.

7. Reembolsos

Consulta la política de reembolso. Aplica a la primera compra, con un reembolso por cliente. Lemon Squeezy es el merchant of record y procesa los pagos y reembolsos. Podemos denegar solicitudes con evidencia de abuso, compartir license keys o uso masivo para evaluar y devolver.

8. Contacto

Para soporte, escribe a packlens@proton.me o abre un issue en GitHub Issues. No incluyas license keys, API keys ni datos personales.
