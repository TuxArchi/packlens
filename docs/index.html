Preguntas frecuentes

Lo importante, claro.

¿Es open source?

Sí. El código está publicado con licencia MPL-2.0. Las funciones Pro también son públicas y se activan con una licencia; el gate es una comodidad, no una protección criptográfica.

¿Usa IA?

No. No hay modelos, prompts ni proveedores de IA. Los análisis y las propuestas son reglas locales y datos públicos de YouTube.

¿Dónde van mis datos?

El análisis se queda en tu navegador. La license key se envía a Lemon Squeezy. Las búsquedas y la auditoría usan tu API key de YouTube hacia Google. El CSV se procesa localmente. No hay telemetría.

¿Necesito una API key?

Para keywords con datos completos y para la auditoría del canal, sí: una API key gratuita de YouTube Data API v3. El packaging, el SEO, los tags y el resumen de 48 h funcionan sin clave, con datos públicos.

¿Funciona con videos programados?

Sí para packaging, SEO y tags del editor. El rendimiento y el CSV necesitan que el video esté publicado y tenga datos.

¿Hay reembolsos?

Sí, 14 días para la primera compra. Consulta la política de reembolso.
