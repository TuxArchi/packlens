# PackLens brand kit

- `packlens-logo-horizontal-dark.png` — logo para fondos oscuros.

- `packlens-cover-1200x630.png` — portada para Open Graph/redes.
- `packlens-feature-packaging-1600x900.png` — imagen de producto: Packaging.
- `packlens-feature-keywords-1600x900.png` — imagen de producto: Keywords y títulos.
- `packlens-feature-description-1600x900.png` — imagen de producto: Descripción.
- `packlens-feature-performance-1600x900.png` — imagen de producto: Rendimiento y CSV.

## Uso recomendado

- **Lemon Squeezy**:
  - Banner: `packlens-banner-1600x900.png`
  - Imagen de producto: `packlens-square-1080.png` o el banner.
  - Galería: las 4 imágenes `feature-*`.
  - Logo/avatar: `packlens-icon-512.png`.
- **AMO**:
  - Icono: `packlens-icon-512.png`.
  - Capturas: usa las `feature-*` o capturas reales de la extensión.
- **GitHub/README**:
  - `packlens-banner-1600x900.png`
  - `packlens-logo-horizontal-dark.png`
- **Documentos/fondos claros**:
  - `packlens-logo-horizontal-light.png`
