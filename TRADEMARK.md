El código de este repositorio está bajo la Mozilla Public License 2.0. **Eso no incluye el nombre PackLens ni el logo.**

## Qué puedes hacer

- Usar, modificar y distribuir el código según la MPL-2.0.
- Crear un fork y publicarlo con **otro nombre** y **otro icono**.
- Mencionar que tu proyecto está basado en PackLens, sin sugerir que es oficial.

## Qué no puedes hacer

- Publicar un fork usando el nombre **PackLens** o un nombre confusamente similar.
- Usar el logo de PackLens como icono de tu fork.
- Sugerir afiliación, patrocinio o aprobación por parte del proyecto original.

## Contribuciones

Al contribuir aceptas que tu contribución se licencia bajo MPL-2.0 y que el proyecto puede usarla en el núcleo abierto. No se concede permiso para usar la marca en productos derivados.

Si necesitas permiso para usar la marca, contacta con los mantenedores a través del repositorio.
